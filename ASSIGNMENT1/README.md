# Assignment 1

This folder contains C programming exercises for Assignment 1.

## Surface Area of a Sphere

`Surface area of sphere.c` is a command-line program that calculates the surface area of a sphere using:

```text
Surface area = 4 × π × radius²
```

The program asks for the sphere's radius, calculates the result using `π = 3.14159`, and prints the surface area to two decimal places.

### Compile and run

```bash
gcc "Surface area of sphere.c" -o sphere
./sphere
```

Enter the radius when prompted. The program expects a numeric value.
